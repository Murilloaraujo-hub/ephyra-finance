# Imagens do tutorial

Esta pasta contém as imagens exibidas por `js/onboarding.js`.

Arquivos esperados:

- `tutorialwelcome.png`
- `tutorial-dashboard.png`
- `tutorial-transacoes.png`
- `tutorial-metas.png`
- `tutorial-mercado.png`
- `tutorial-resumo.png`
- `tutorial-conquistas.png`
- `tutorial-ephyra.png`
- `tutorial-ready.png`

Enquanto uma imagem estiver ausente, o tutorial exibe automaticamente o cartão
de reserva correspondente. Para melhorar o carregamento em celulares, prefira
imagens otimizadas com até aproximadamente 500 KB.
